# OligoGym Benchmark Workspace

This directory is reserved for standardized external benchmarking of OligoTox models.

Subfolders:
- raw/: downloaded benchmark datasets
- processed/: normalized benchmark-ready tables
- splits/: leakage-aware train/val/test splits
- configs/: benchmark run configs
- results/: metrics, curves, and comparison outputs

Planned benchmark tracks:
- gapmer hepatotoxicity
- siRNA immunostimulation
- ASO efficacy
- siRNA efficacy
